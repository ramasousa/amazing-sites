# Works Wheel

Um índice de portfólio em React que é uma roda que se gira: um anel de capas que abre num tambor vertical.

- `src/components/ui/works-wheel.tsx` — o componente (só React, CSS embutido)
- `src/components/works-wheel-demo.tsx` — a demo em tela inteira, com capas do Unsplash

```sh
npm install
npm run dev      # desenvolvimento
npm run build    # typecheck + build em dist/
```
